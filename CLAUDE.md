# FinAlly Project - the Finance Ally

All project documentation is in the `planning` directory.

The key document is PLAN.md included in full below; the market data component (Dhan WebSocket feed, simulator, unified interface) is built in `backend/app/market/` and documented in `planning/MARKET_DATA_DESIGN.md`, `MARKET_INTERFACE.md`, `MARKET_SIMULATOR.md` and `DHANHQ_API.md`; implementation status is tracked in PLAN.md section 13. To watch live prices in a terminal: `cd backend && uv run python -m demo` (how-to in `Docs/help.md`). Consult these docs only when required. The remainder of the platform is still to be developed.
